# 问题
路由器ABC相互连接，但A是192.168.0.xxx  连接光猫、没有部署代理服务，B、C都是192.168.123.xxx、连接A、B部署代理服务。 现在B、C可以访问A里的主机，但是A无法访问B、C里的主机

# ip
## ip route

`ip route add <目的地址> via <网关> [dev <接口>] [metric <值>]`

- 走 192.168.1.1 时本机是 192.168.1.100
`sudo ip route add 192.168.2.0/24 via 192.168.1.1 src 192.168.1.100`

- 访问 192.168.2.0 走 192.168.1.1 且 通过网卡eth0
`sudo ip route add 192.168.2.0/24 via 192.168.1.1 dev eth0`

网关不是指设备本身，而是设备的网络层，不需要网关（三层、路由器）时就是走二层（交换机）。
不经过网关指的是:这个 IP 包从头到尾都不会被任何路由器在网络层(L3)拆包、改包头、再转发出去。它精确地说是"不需要经过网关做路由转发",而不是"物理上不经过任何设备"。
