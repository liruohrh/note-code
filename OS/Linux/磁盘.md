- 查看某个entry `du -sh /path`
  - 连续输出2层的 `du -xhd 2 /path`
  - `| awk -F'/' 'NF == 4'` 表示分割 / ，保留4个元素的
  - `find /path/to/dir -mindepth 1 -maxdepth 1 -print0 | du -sh --files0-from=-` 
  - `fd --print0 . /path/to/dir | du -ch --files0-from=- `
    - `fd --type f . /path/to/dir -X du -ch --`

- 查看已经删除但是未被释放的
  - `sudo lsof +L1` 筛选链接数小于 1 的文件

```bash
#!/usr/bin/env bash
# 列出已删除但仍被进程占用的文件(按大小降序)，最后给出去重后的实际占用
MIN=${1:-1048576}   # 最小字节数，默认 1 MiB

sudo lsof -nP +L1 -FpcfDisn 2>/dev/null |
awk -v min="$MIN" '
function flush() {
    if (fd != "" && size ~ /^[0-9]+$/ && size + 0 >= min + 0)
        printf "%s\t%s\t%s\t%s\t%s\t%s\n", size, pid, fd, cmd, dev ":" ino, name
    fd = size = name = dev = ino = ""
}
/^p/ { flush(); pid = substr($0, 2); cmd = ""; next }
/^c/ { cmd  = substr($0, 2); next }
/^f/ { flush(); fd = substr($0, 2); next }
/^D/ { dev  = substr($0, 2); next }
/^i/ { ino  = substr($0, 2); next }
/^s/ { size = substr($0, 2); next }
/^n/ { name = substr($0, 2); next }
END  { flush() }
' |
sort -t $'\t' -k1,1nr |
awk -F '\t' '
function human(n) {
    n += 0
    if (n >= 1073741824) return sprintf("%.2f GiB", n / 1073741824)
    if (n >= 1048576)    return sprintf("%.2f MiB", n / 1048576)
    if (n >= 1024)       return sprintf("%.2f KiB", n / 1024)
    return sprintf("%d B", n)
}
{
    printf "%12s  PID=%-7s FD=%-5s %-16s %s\n", human($1), $2, $3, $4, $6
    if (!seen[$5]++) total += $1
}
END { if (NR) printf "\n%12s  合计(同一文件只算一次，%d 条记录)\n", human(total), NR }
'


# 迁移


## rsync
sudo rsync -aHAXS --numeric-ids --info=progress2 /mnt/ws/data/wp /mnt/ws/data/wps && sudo rm -rf /mnt/ws/data/wp


1. -a：归档模式，等于 -rlptgoD：
   a. r：递归复制子目录。
   b. l：符号链接按链接本身复制，不复制它指向的内容。
   c. p：保留权限。
   d. t：保留修改时间。
   e. g：保留属组。
   f. o：保留属主。
   g. D：保留设备文件和特殊文件。
2. -H：保留硬链接，否则同一个文件的多个硬链接会被复制成多份。
3. -A：保留 ACL（扩展的权限设置）。
4. -X：保留扩展属性（xattr）。
5. -S：高效处理稀疏文件，不把文件里的"空洞"写成实际占用空间的零。
6. --numeric-ids：按 UID/GID 数字原样保留属主，不按用户名去对应。100032 这种容器映射出来的用户在宿主机上没有用户名，必须靠这个参数才能保持不变。
7. --info=progress2：显示整体进度（总百分比、速度、剩余时间），而不是逐个文件刷屏。
8. 源路径末尾没有 /：复制目录本身，得到 目标/wp；如果写成 wp/，就是只复制里面的内容。

### --numeric-ids

复制时按数字 UID/GID 原样保留文件的属主和属组，不按用户名去转换。
文件属主在磁盘上存的是什么
文件系统里记录的是数字，比如 1000、100000，不是用户名。ls -l 显示的 scott，是 ls 去 /etc/passwd 里查出来的名字。
rsync 默认的做法：rsync 会按名字来对应：先在源端把 UID 转成用户名，到了目标端再把用户名转回 UID。
- 在同一台机器上复制，源和目标查的是同一个 /etc/passwd，有名字的用户结果都一样。
- 跨机器复制时，同一个用户名在两台机器上可能对应不同的数字。按名字对应，能保证文件属于"同一个人"。

什么时候必须加
1. 属主没有对应的用户名时。 比如你这里容器映射出来的 100000、100032、101000，宿主机的 /etc/passwd 里没有这些用户。不加 --numeric-ids 时，rsync 碰到查不到名字的 UID，一般也会保留原数字，但行为取决于版本和具体情况，不够可靠。加上之后就明确规定"数字是多少就写多少"。
2. 数字的含义只在特定环境里成立时。 比如 33 在宿主机上是 www-data，在容器里也是 www-data，但这层对应关系是由数字决定的，不是由名字决定的。容器里的 MySQL、PostgreSQL 等程序认的也是数字，只要数字变了，它们就会因为权限问题启动失败。

# 挂载

- 系统自带的磁盘工具可能不支持永久挂载（如ubuntu）

```bash

# 查看分区id
blkid
# 修改分区label
sudo e2label /dev/nvme0n1p5 newlabel
# 挂载分区
sudo echo 'UUID=342cb1a3-fa92-47ae-b810-1c3d87f6dea5 /mnt/ws ext4 defaults 0 0' >> /etc/fstab
# 挂载目录
sudo echo '/mnt/x/y  /home/x/y  none  bind,x-systemd.requires-mounts-for=/mnt/x  0 0' >> /etc/fstab

#
sudo systemctl daemon-reload
sudo mount -a
# 查看挂载
findmnt ~/ws
```
