# 站点源


## 站点索引

- 原始全网爬取/索引：Common Crawl、Open Web Index。
- 独立网页语料/档案：ClueWeb、Internet Archive。
- Common Crawl 的清洗衍生语料：C4、OSCAR、FineWeb、RefinedWeb、RedPajama。
- 非通用网页数据源：GDELT（新闻/事件）、The Stack（代码）、Wikipedia、Books3 等。

### commoncrawl

- https://index.commoncrawl.org/
里面有很多cdx索引文件，可以直接下载，也可以用 [api查询](https://github.com/webrecorder/pywb/wiki/CDX-Server-API) 。
用 [工具](https://commoncrawl.github.io/cc-examples/?kw=CDX&official=1&open=scdx) 查询或者下载 。
