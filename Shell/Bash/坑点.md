# 自动加载的脚本

| Bash 启动方式          | 读取                                                          |
| ------------------ | ----------------------------------------------------------- |
| `bash -l`          | `/etc/profile` → `~/.bash_profile`/`.bash_login`/`.profile` |
| `bash -il`         | 上面 + `~/.bashrc`（通常由 profile 间接加载）                          |
| `bash`             | `~/.bashrc`                                                 |
| `bash -c '...'`    | `$BASH_ENV` 指定的文件                                           |
| `bash --noprofile` | 跳过 profile                                                  |
| `bash --norc`      | 跳过 `.bashrc`                                                |

## 如agent、启动脚本所用的

- ~/.bash_env
```bash
export PATH="$HOME/.local/bin:$PATH"
source /etc/environment
# mise
eval "$(mise activate bash)"
```


- 在用户环境下的systemd服务（在脚本里可以用~,有设置$HOME,但是路径字段还是得绝对路径、不会自动加载任何用户配置）
```
[Unit]
Description=service monitor
After=network.target

[Service]
WorkingDirectory=/opt/servnitor
Environment="BASH_ENV=~/.bash_env"
ExecStart=/bin/bash /opt/servnitor/start.command
Restart=always
RestartSec=10
User=liruohrh

[Install]
WantedBy=multi-user.target
```

# 字符串展开
- `a="a b"   xxx "$a" `
	- 如果是`xxx "$a"`，则a会作为一个参数传入xxx
	- 如果是`xxx $a`，则a会根据空格展开为2个参数传入xxx
	- 但如果a是数组如`a=(a b) `，那么无论是`xxx "${a[@]}"`还是`xxx ${a[@]}`都是2个参数传入xxx
