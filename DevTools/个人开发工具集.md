
- fzf 模糊查找
	- `eval "$(fzf --bash)"`
	- Ctrl-R：历史记录搜索
	- Ctrl-T：文件搜索
	- Alt-C：目录搜索
	- `**<Tab>`：模糊补全

- zoxide 智能跳转：高级版cd，能学习常用文件夹并允许从几乎任何地方直接跳转。
- bat 增强查看：高级版cat，提供语法高亮、行号和 Git 集成，让文本和代码阅读体验更好。
- btm 实时监控：高级版top，提供 CPU、内存、磁盘活动和网络流量的实时可视化视图，快速定位占用资源的进程。
- ripgrep 高效搜索：高级版grep，更快更智能，递归搜索时自动忽略 Git 忽略的文件和无关目录。
- fd 现代查找：高级版find，语法简单易记且默认忽略隐藏文件。
- delta 优化 Git 比较：高级版git diff，添加语法高亮、行号和并排视图，使审查大型拉取请求更轻松。
